# BTC Signal AI — прототип 0.1.0

Веб-прототип для анализа BTC-USDT по публичным рыночным данным OKX. Выдаёт эвристические сигналы UP / DOWN / WAIT для горизонтов 5 и 15 минут. Не размещает сделки и не использует приватные API-ключи.

## Требования
- Python 3.10+
- Интернет для обращения к публичному API OKX

## Запуск локально

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS / Linux:
```bash
source .venv/bin/activate
```

Установить зависимости и запустить сервер:

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000

Проверка API:
- `http://127.0.0.1:8000/api/health`
- `http://127.0.0.1:8000/api/analysis`

## Что реализовано
- Публичные закрытые 1-минутные свечи OKX (`BTC-USDT`)
- Расчёт EMA 9/21/50, RSI 14, MACD, ATR и краткосрочного импульса
- Отдельные эвристические оценки для 5- и 15-минутного горизонта
- Автообновление страницы каждые 15 секунд
- Причины формирования сигнала и режим WAIT

## Ограничения и следующие шаги
1. «Сила модели» — эвристический показатель, не вероятность выигрыша.
2. Пока нет полноценного бэктеста, учёта цены контракта UP/DOWN, выплат, комиссии и проскальзывания.
3. Для оценки качества нужно сохранить сигналы и последующие цены, затем проверить результаты вне обучающего периода.
4. Для эксплуатации добавить повторные подключения, мониторинг задержки данных, тесты и защищённое размещение.
5. Перед тем как использовать сигналы в реальной торговле, проверьте, что цена базового актива и правила расчёта контракта OKX соответствуют конкретному продукту, которым вы торгуете.

## Источник данных
Публичный API OKX, без API-ключа: `https://www.okx.com/api/v5/market/candles`.
Документация: https://www.okx.com/docs-v5/en/
